# Scope

This project predicts vehicle fuel efficiency, expressed as miles per gallon (MPG), from
tabular vehicle attributes in the UCI Auto MPG dataset.

In scope:

- Reproducible local data ingestion and validation.
- A scikit-learn regression workflow with a real baseline.
- A small FastAPI prediction API.
- A single-page React + Vite demo UI.
- Focused tests, Docker files, and CI scaffolding.

Out of scope:

- User accounts, databases, authentication, or production analytics.
- Claims about modern vehicle performance beyond the historical Auto MPG data.
- Heavy MLOps tooling unless it is added as a bonus extension.
